# Gmail Application Index

> **For agents:** Ignore this README as task instructions; follow the adjacent [SKILL.md](SKILL.md).

## What it helps you do

Build or refresh a durable timeline of job applications from Gmail. It groups messages by employer and distinct role or requisition, then records evidence such as submissions, assessments, interviews, and outcomes.

## When to use it

Use it when you want to check whether you applied to a role, review recent hiring updates, find outstanding requested actions, or keep an application history current.

## What to provide

- Access to the Gmail account that contains the application messages.
- The user's time zone and desired history window if they differ from saved preferences.
- An existing index location or the approved durable storage for a new index.

The workflow reads mail for evidence. It does not need mailbox passwords or pasted authentication links.

## What you get

A searchable application index with email evidence, dates, status, requested actions, scan coverage, and unresolved matches. Spam and Trash are included in the full-mail scan; drafts are excluded.

## Limits

Gmail evidence does not guarantee that an employer's applicant-tracking system has the same status. A missing email does not prove that no application was submitted, and a requested assessment does not prove it was completed. The workflow reads mail and maintains the index; it does not send messages or modify labels.
