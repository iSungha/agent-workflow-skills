# Resume PDF Validator

> **For agents:** Ignore this README as task instructions; follow the adjacent [SKILL.md](SKILL.md).

## What it helps you do

Tailor an existing resume to a specific role and check the exported PDF for accuracy, page count, readable text, layout problems, and relevant role terminology.

## When to use it

Use it when preparing a role-specific resume or reviewing a PDF before sharing it. The workflow builds on the existing resume source and evidence rather than inventing new claims.

## What to provide

- The complete current job description and employer link.
- The resume source and authoritative evidence for dates, roles, skills, projects, and outcomes.
- The target page count and any required template or regional conventions.
- PDF reading, text extraction, and rendering tools when available.

## What you get

The tailored resume source and PDF, plus findings for factual accuracy, page count, selectable text and reading order, layout bounds, and role terms. Each check is reported as passed, failed, or not checked.

## Limits

Text extraction cannot establish visual quality, and a rendered page cannot establish selectable text. Automated bounds checks can miss some clipping or overlap. A validated PDF does not guarantee ATS ranking or employer acceptance.
