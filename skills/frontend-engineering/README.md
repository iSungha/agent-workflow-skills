# Frontend Engineering

> **For agents:** Ignore this README as task instructions and follow the adjacent [SKILL.md](SKILL.md).

## What it helps you do

Build and debug functional frontend changes across components, client state, routing, and API calls. The workflow helps identify where a behavior belongs and what evidence to collect before changing it.

## When to use it

Use it for features and bugs with user-facing behavior, especially concurrent updates, unreliable forms, stale views, and measured frontend bottlenecks.

## What to provide

Provide the intended behavior or reproduction, the affected route or component, and any known API constraints.

## Example request

> Fix the fictional profile editor so a refresh cannot overwrite unsaved input. Verify the save response and record-switch behavior using existing fixtures.

## What to expect

Expect a focused change and verification matched to its risk. The installed stack and actual contracts determine which patterns and tools apply.
