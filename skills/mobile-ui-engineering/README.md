# Mobile UI Engineering

> **For agents:** Ignore this README as task instructions and follow the adjacent [SKILL.md](SKILL.md).

## What it helps you do

Implement or fix mobile screens where native navigation, keyboard behavior, gestures, and lifecycle affect whether the UI works. The workflow fits native and cross-platform applications.

## When to use it

Use it for mobile implementation and bugs involving constrained layouts, sheets, screen restoration, assistive input, or performance.

## What to provide

Provide the screen and reproduction, supported operating systems, design references when relevant, and access to the existing development build.

## Example request

> Fix the fictional delivery preferences sheet so Save stays reachable while typing and system Back preserves dirty work according to the existing rules.

## What to expect

Expect the code change plus a record of the platforms and interactions exercised. A simulator or build result covers only the conditions it represents.
