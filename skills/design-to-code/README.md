# Design to Code

> **For agents:** Ignore this README as task instructions and follow the adjacent [SKILL.md](SKILL.md).

## What it helps you do

Turn an approved design into working UI inside an existing codebase. The skill helps teams adopt a new layout without dropping current actions, replacing shared architecture, or treating mock prototype data as product behavior.

## When to use it

Use this when a design exists and the task is to implement it. For an independent review of a running interface, use the Visual UI Evidence Auditor.

## What to provide

Provide the approved design, the route or screen to change, and any expected states or behaviors. Links, exports, and screenshots are all useful if they identify the intended revision.

## Example request

> Implement the attached fictional settings design in the current app. Keep the existing save, reset, and error behavior, and show where you checked the responsive layout.

## What to expect

Expect an implementation and a short account of the states verified and any deviations. A single design frame leaves gaps about interaction and other viewports.
